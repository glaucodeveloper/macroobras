# Páginas do frontend MacroObras

Cada rota possui um único arquivo. Componentes específicos permanecem no arquivo da própria página; somente primitivas visuais genéricas continuam em `ui/components.js`.

O estado global e as transições da aplicação ficam em `core/machine-state.js`.
